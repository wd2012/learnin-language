# LinguaPath 产品需求文档（PRD）

## 1. 项目定位
面向个人长期使用的英语与日语听说训练微信小程序。核心目标是提高英语/日语听力、口语与词汇能力；在日本生活和寻找软件工程师岗位时能够使用。项目只需微信体验版，不以商业化或正式上架为目标。

## 2. 用户画像与学习目标
- 用户熟悉 React、TypeScript、Taro 和 NestJS，能够阅读英文技术文档，但英语口语和听力需要系统训练。
- 英语重点：日常交流、技术表达、架构设计介绍、软件工程师面试、英文会议。
- 日语重点：五十音、N5→N4→N3、赴日生活（便利店、交通、租房、医院、托育）、求职沟通。
- 每天可选 20/40/60 分钟，强调高频开口、复习和低摩擦操作。

## 3. 核心功能与验收标准
### P0：本地可用的学习闭环
1. 中英日界面中文优先；英语和日语课程可切换。
2. 每日任务：首页展示今日听力、跟读、独立表达、词汇任务及完成状态。
3. 听力：播放/暂停、逐句播放、循环、变速、显示/隐藏原文与中文翻译；支持听力选择题和听写。
4. 跟读：开始/停止录音、回放自己的录音，录音失败和权限拒绝有提示；不将录音无提示上传。
5. 词典：英语/日语单词查询，中文释义、词性、发音、例句；日语优先呈现假名，英语优先呈现音标。初期允许授权的离线词表，联网词典须有稳定授权与错误处理。
6. 生词本：收藏、移除、搜索，学习进度存本地；复习支持简单间隔复习策略。
7. 课程：至少 28 天英语学习计划和日语 N5 入门样例，每日任务可执行而不只是标题。
8. 学习统计：打卡记录、完成课程、近7天学习趋势、单词复习情况。
**验收：** 在微信开发者工具和至少一台真机上操作完整学习流程；断网状态下本地功能可正常使用；不假装未实现的功能已上线。

### P1：AI 逐轮口语训练
1. 用户按住/点击录音，语音识别 ASR 为英语或日语转写文本。
2. AI 对用户回答进行语法纠错、自然表达建议、具体鼓励与追问；中文可用于解释，不替代目标语言练习。
3. TTS 播放 AI 回复；用户可查看对话文字、重播、继续下一轮。
4. 场景：英语技术面试（React、TypeScript、BFF、低代码）、日语生活对话（购物、交通、托育等）。
5. 上传语音前提示；服务端设置鉴权、请求限额、超时和失败重试；密钥不进入小程序包。
**验收：** 完成至少5轮对话；识别或AI失败时有清晰提示；错误识别不虚构发音评分。

### P2：增强体验
- 实时语音对话（低延迟、打断和双向音频），在验证平台能力和服务成本后再做。
- 专项发音评测（独立的语音评测服务，不能把ASR当作评分）。
- 云端同步、个人趋势分析、内容持续更新。

## 4. 内容结构
- 英语：自我介绍、日常生活、职场会议、解释项目、React/TypeScript、NestJS/BFF、低代码设计、技术面试。
- 日语：五十音、N5词汇与基础句型、数字日期、购物、问路、餐厅、托育沟通、职场入门。
- 单课数据建议包括：id, language, level, topic, duration, text, translation, audioSegments, vocabulary, comprehensionQuestions, speakingPrompts。
- 内容须人工核验正确性，并尊重词典、音频及教材版权。

## 5. 非功能要求
- 微信体验版为交付目标；不需要正式公开发布。
- 个人学习数据优先本地存储；服务端语音明确保留周期与删除方式。
- 低资源手机兼容，具备音频清理、超时、异常兜底。
- 可测试、可维护，严格区分已经实现与计划中的功能。

## 6. 现状
当前仓库代码仅包含4个示例页面、6节文本课程、录音回放和本地打卡。听力音频、AI、完整词典、课程计划尚未实现；是否能构建需要验证。

## 7. 开发顺序
- 0.1：依赖安装、TypeScript检查、微信构建和真机基础功能验证。
- 0.2：完整听力播放器、28天英语课程、日语N5入门、词典和生词本。
- 0.3：NestJS API、ASR、AI纠错、逐轮语音对话、TTS。
- 0.4：复习统计优化和更多场景；实时音频另行评估。
