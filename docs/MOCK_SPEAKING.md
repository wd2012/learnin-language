# 英语／日语逐轮口语练习基础流程

## 范围与现状

本次先实际执行 typecheck 和微信构建，再在独立功能分支增加 NestJS 后端和 Taro 练习页面。不调用真实付费 API，不购买云资源，不需要服务商凭据。`PROVIDER_MODE` 仅允许 `mock`；这是当前实现范围，不是永久禁止付费 AI。后续真实验证必须由用户明确确认并安全配置凭据。

PRD 的完整 P0、真实 ASR、语法纠错、自然表达改写、语音合成和手机端五轮验收尚未完成。本次五轮验证是本地 Mock HTTP 集成测试，不能代替中文／英文／日文语音能力或真机验收。

## 安装与启动

已在 Node 24.19.0、npm 11.9.0 验证；要求 Node 22.8+。使用现有仓库，不需要创建 worktree。

```bash
# 仓库根目录
npm ci
npm --prefix server ci
npm run typecheck
npm test
npm run server:test
npm run build:weapp

# 终端一：先编译再启动 NestJS，仅监听 127.0.0.1:3000
npm run server:dev
# 终端二：微信编译监听
npm run dev:weapp
```

服务端开发命令会观察编译产物；修改 `server/src` 后运行 `npm run server:build`，进程自动重启。也可在第三个终端运行 `cd server && ./node_modules/.bin/tsc -p tsconfig.json --watch`。正式单次启动可使用 `npm run server:build` 后 `npm --prefix server start`。

微信开发者工具导入根目录 `project.config.json`，`dist/` 是小程序目录。仅本地调试时允许工具跳过域名检查；这不能作为体验版的网络配置。默认 API 地址为客户端 service 内的本机地址，仅适用于开发者工具。手机的回环地址不指向电脑。当前服务端强制本机监听，且 `NODE_ENV=production` 拒绝启动，不能作为公网部署。

进入首页 → “逐轮口语练习 · Mock” → 连接服务 → 选择语言和场景 → 输入文本，或录音、确认上传、修改演示文本 → 发送 → 查看反馈和下一轮问题 → 生成／重播提示音。可分别完成至少五轮英语、日语流程。切换语言或场景会清空本页对话；原有课程和打卡入口保持可用。

## Provider 和接口

`server/src/providers.ts` 定义 ASR、LLM、TTS 接口与 Nest 注入标识。接口接受 `AbortSignal`；HTTP服务只有 Mock 实现被注册，不会发起真实供应商请求。另有独立的腾讯云／百炼适配器及手动验证入口，见 [真实 Provider 指引](REAL_PROVIDERS.md)；它们尚未通过真实服务验证。新增真实实现时必须继续保留取消、输入校验、费用计量与错误处理，并验证供应商响应结构。

- ASR：接受音频，但返回按语言选择的固定演示文本，不读取音频中的词语；前端明确标记且允许修改。
- LLM：按语言、场景和最近上下文轮数返回固定追问；纠错与改写字段仅回显原句，示例为固定内容。不是实际语法评估，也没有发音评分。
- TTS：返回原创生成的 0.25 秒 WAV 提示音，明确标记 `kind=mock-tone`；不朗读回复。前端缓存本轮结果，重播不再次请求 TTS。

| 接口 | 内容 |
| --- | --- |
| `POST /api/session` | 创建一小时有效的内存本地开发会话，不提供生产用户身份认证 |
| `POST /api/speech/transcribe` | multipart：`audio` 文件、`language=en/ja` |
| `POST /api/conversation/turn` | `language`、`scene=interview/daily`、可编辑 `text`、最多20条 `history` |
| `POST /api/speech/synthesize` | `language`、`text`；返回 Base64 WAV 演示提示音 |
| `GET /api/usage/monthly` | 当前北京时间月份的次数、用量、模拟金额、预算提醒；`/api/usage` 为别名 |

除创建会话外，接口要求 `Authorization: Bearer <本地会话>`。客户端仅在内存保存会话，不写入存储；没有内置共享密钥。服务端最多保留100个未过期会话，重启后失效。此机制只适合本机开发，真实部署需要微信登录校验与用户级鉴权。

## 输入限制、隐私和错误

- 单次录音最长60秒；服务端解析 MP3/WAV/AAC 元数据验证时长，允许100毫秒编码填充。不只信任客户端声明、扩展名或 MIME。无法解析、空文件、超过2 MiB、异常 MIME 均拒绝。
- 文本最多2000字符，历史最多20条；拒绝空白、非法语言／角色／场景、额外字段。JSON 请求体上限64 KiB。
- 上传使用内存缓冲；服务端不写入录音，不记录原始音频、对话、会话 token。处理完成后释放引用；没有长期音频存储或对话数据库。
- 前端申请麦克风权限；上传前弹出说明，可取消；ASR失败可手动输入，LLM失败保留输入，TTS失败保留文字。401提示重新连接，429提示稍后重试或预算不足，超时／断网提示手动重试。不自动重发生成请求；响应丢失后手动重试可能再次计数，真实计费接入前还需要幂等请求与账单对账。
- 录音服务对 Taro 的共享 RecorderManager 只注册一组监听器；每次录音的页面回调完成后释放。卸载时停止录音并清理迟到的临时文件，避免把上一页的停止事件送给下一页。退后台停止录音、播放器并删除本次文件。播放错误有提示，卸载销毁音频对象。平台删除失败采取尽力清理，仍需真机检查。
- 全服务固定窗口限流，默认每分钟30次，包含会话创建和查询，不能通过更换会话绕过。超限返回429和 `Retry-After: 60`。这是单进程本地限流，不是多实例方案。
- Provider 默认5秒超时，通过 AbortSignal 取消并释放本轮模拟预算。客户端10秒超时。没有真实供应商重试或付费调用。

## 用量与月度模拟预算

目标预算参考 PRD 的每月20–50元人民币。当前默认20元**模拟**预算，实际费用始终0。演示费率 ASR 1000、LLM 2000、TTS 1000 微元／成功请求只用于测试提醒机制，不是任何厂商报价或成本预测。1元=1,000,000微元。

服务端成功完成后记录 ASR实际音频时长、LLM输入／输出模拟 Token、TTS字符数和各操作次数。Token 按字符估算（英语4字符／Token、日语1字符／Token），不是模型实际用量。真实 Provider 应使用官方返回的实际用量和实时价格。

北京时间每月自动换月；达到80%发出软提醒，超过剩余模拟额度的操作返回429。调用前原子预留，失败回滚，防止并发突破模拟预算。这只控制当前单进程的演示请求；全部统计在内存，重启清零，不能充当持久化账单或云成本硬封顶。后续应补持久化用户账本、供应商账单告警与服务器／域名／流量费用统计。

可通过进程环境设置以下非秘密参数，不需要 `.env` 文件：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PROVIDER_MODE` | `mock` | 其他值直接拒绝启动 |
| `PORT` | `3000` | 1–65535；客户端本地地址须匹配 |
| `MOCK_MONTHLY_BUDGET_MICROS` | `20000000` | 正整数，人民币模拟预算微元 |
| `REQUESTS_PER_MINUTE` | `30` | 全服务固定窗口请求上限 |
| `PROVIDER_TIMEOUT_MS` | `5000` | Provider 超时，最大30000毫秒 |
