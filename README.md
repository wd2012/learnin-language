# LinguaPath · 英语与日语学习微信小程序

基于 Taro + React + TypeScript 的个人语言学习项目，目标为提高英语和日语的听力、口语与词汇能力。

## 项目状态

目前处于初始化阶段；功能仍待开发及真实设备验证。

## 功能规划

- 英语日常交流、技术英语、软件工程师面试练习
- 日语五十音、N5入门及赴日生活场景训练
- 逐句听力、循环、变速、听写与字幕
- 录音回放、语音识别、AI逐轮对话与纠错（后续需服务端）
- 英日词典、发音、例句、生词本和间隔复习
- 每日学习任务、打卡和进度统计
